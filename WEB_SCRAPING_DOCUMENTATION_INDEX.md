```
Web Sources (Medical Sites, PubMed, etc.)
    ↓ (WebSearchBotlet)
Multi-Engine Search
    ↓ (BeautifulSoup4)
HTML Parsing & Content Extraction
    ↓ (Medical NLP)
Content Filtering & Validation
    ├→ FAISS Vector Index (212+ embeddings)
    ├→ PostgreSQL pgvector (1536-dim embeddings)
    └→ RAG Pipeline (Response Generation)
    ↓
    ├→ SIB Chat API (/api/chat)

    ├→ Knowledge Search (/knowledge/search)
```
