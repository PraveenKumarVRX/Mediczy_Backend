🔧 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Error: "invalid_client"
-----------------------
Cause: Client ID doesn't exist or is incorrect
Fix:   Verify Client ID in Google Cloud Console matches:
       982376166047-j975co5qc5enqhcesggbsee3obnj7tqa.apps.googleusercontent.com


Error: "redirect_uri_mismatch"
-------------------------------
Cause: Redirect URI not configured or doesn't match exactly
Fix:   In OAuth Client settings, ensure these are added:
       • http://localhost:9443
       • https://mediqzy.com
       
       Check for:
       - Trailing slashes (should NOT have)
       - Correct protocol (http vs https)
       - Exact domain spelling


Error: "access_denied"
----------------------
Cause: User denied permission OR scopes not configured
Fix:   1. Check OAuth consent screen has all 5 fitness scopes
       2. User must click "Allow" not "Deny"


Error: "Popup blocked"
----------------------
Cause: Browser is blocking the OAuth popup
Fix:   Allow popups from mediqzy.com in browser settings


Error: "Fitness API not enabled"
---------------------------------
Cause: Google Fitness API not enabled for project
Fix:   Enable at: https://console.cloud.google.com/apis/library/fitness.googleapis.com?project=mediczy-624ed
