FEATURE BREAKDOWN
================================================================================

1. INSURANCE CLAIMS MANAGEMENT (5 endpoints)
   ✅ Policy Management
      - GET /insurance/policies - List policies with filtering
      - POST /insurance/policies - Create new policy
   
   ✅ Claims Workflow
      - GET /insurance/claims - List claims with stats
      - POST /insurance/claims - Submit claim (auto-generates claimNumber)
      - PATCH /insurance/claims/:id - Update status, approve, reject, pay
   
   Status Workflow: submitted → under_review → approved/rejected → paid
   
   Key Features:
   - Unique claim numbers (CLM-timestamp-random)
   - Status tracking and approval workflow
   - Claim amount and approved amount tracking
   - Rejection reason logging
   - Payment date tracking
   - Comprehensive statistics (submitted/under_review/approved/rejected/paid)

2. MEDICAL RECORDS SYSTEM (3 endpoints)
   ✅ Record Management
      - GET /medical-records - List records with filters
      - POST /medical-records - Create record
      - PATCH /medical-records/:id - Update record
   
   Key Features:
   - Record number auto-generation (MR-timestamp-random)
   - Record types: consultation, discharge, follow-up, emergency
   - JSONB support for vital signs, prescriptions, documents
   - Patient-doctor-appointment relationships
   - Date range filtering
   - Flexible data storage (JSONB allows adding fields without migration)

3. EHR SYSTEM (3 endpoints)
   ✅ Patient EHR Management
      - GET /ehr/:patientId - Get patient EHR
      - POST /ehr - Create EHR
      - PATCH /ehr/:patientId - Update EHR
   
   Key Features:
   - One EHR per patient (unique constraint)
   - EHR number auto-generation (EHR-timestamp-random)
   - Comprehensive patient data:
     * Height, weight, blood type
     * Allergies (JSONB)
     * Chronic diseases (JSONB)
     * Current medications (JSONB)
     * Emergency contact (JSONB)
     * Insurance details (JSONB)

4. VITAL SIGNS MONITORING (2 endpoints)
   ✅ Vital Signs Tracking
      - GET /vitals - List vital signs with filters
      - POST /vitals - Record new vital signs
   
   Key Features:
   - Time-series data tracking
   - Multiple readings per patient per day
   - Vital parameters: BP (systolic/diastolic), temp, HR, RR, O2 sat
   - Recorded by staff member with timestamp
   - Latest vital signs filter
   - Date range filtering
   - Patient filtering

SUPPORT & TROUBLESHOOTING
================================================================================

Server Issues:
  $ pm2 restart mediczy-server     # Restart server
  $ pm2 logs mediczy-server         # View logs
  $ pm2 status                      # Check status

Database Issues:
  $ psql -U mediczy_admin -d mediczy_ai -c "\dt"    # List tables
  $ psql -U mediczy_admin -d mediczy_ai -c "SELECT 1"  # Test connection

Test Failures:
  1. Verify server is running: pm2 status
  2. Check server logs: pm2 logs mediczy-server
  3. Verify database: psql test connection
  4. Restart server: pm2 restart mediczy-server
  5. Run tests again: bash test-phase2-endpoints.sh

API Errors:
  404 - Endpoint not found: Restart server (pm2 restart mediczy-server)
  401 - Authentication failed: Check token generation
  400 - Bad request: Check request body format
  500 - Server error: Check server logs (pm2 logs mediczy-server)
