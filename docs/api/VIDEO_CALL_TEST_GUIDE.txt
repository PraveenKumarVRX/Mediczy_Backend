⚠️ COMMON ISSUES & SOLUTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: "Page Not Loading"
  → Check internet connection
  → Verify: http://mediqzy.com is accessible
  → Clear browser cache and try again

Issue: "Camera/Microphone Not Working"  
  → Click the lock icon in browser address bar
  → Allow camera and microphone permissions
  → Refresh the page

Issue: "Can't See Other Person"
  → Make sure BOTH users are in the SAME room (same Room ID)
  → Check that both have allowed camera permissions
  → Verify both users clicked "Join" button

Issue: "No Audio"
  → Check system volume is not muted
  → Verify correct microphone/speaker selected in browser
  → Test audio in browser settings
