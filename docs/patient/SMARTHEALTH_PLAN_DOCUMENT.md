# SmartHealth – Individual Plans (Actuarially Viable Version)

**Platform:** Mediqzy / Mediczy  
**Model:** Managed Care Organization (MCO)  
**Last Updated:** April 28, 2026

---

## 1. Core Design Principles

All plans are built on the following actuarial rules:

| Rule | Implementation |
|---|---|
| No true "unlimited" healthcare | All consults are fair-usage capped per year |
| OPD wallet = subsidy, not cash | Usable only at network clinics/labs |
| Diagnostics = fixed packages / discounts | No open-ended reimbursement |
| Insurance = separate risk pool | Via IRDAI-licensed partner insurers |
| Network-controlled delivery | Approved hospitals, labs, pharmacies only |

**Partner Insurers:**
- ICICI Lombard
- Niva Bupa Health Insurance

## 9. Risk Control Mechanisms

| Mechanism | Implementation |
|---|---|
| Fair-usage consult caps | Per-plan annual GP + specialist limits |
| Subsidy model (not cash) | OPD wallet redeemable only at network providers |
| Fixed diagnostic packages | No open reimbursement — pre-defined test bundles |
| Network control | Approved hospitals, labs, pharmacies only |
| Behaviour shift to prevention | Fitness rewards for health compliance |
