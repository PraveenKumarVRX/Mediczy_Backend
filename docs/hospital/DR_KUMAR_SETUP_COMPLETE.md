## 🎤 AI Medical Scribe - Quick Guide

### How to Use

1. Click the microphone icon 🎤 next to any field
2. Speak naturally in English or Hindi
3. AI automatically:
   - Transcribes speech to text
   - Understands medical terminology
   - Formats medications correctly
   - Suggests standard dosages

### Example Voice Commands

#### For Diagnosis
```
👨‍⚕️ "Patient presents with acute appendicitis, 
    probable gangrenous type, planned for emergency surgery"
```

#### For Medications  
```
👨‍⚕️ "Tablet Paracetamol 650 mg three times daily after meals for 5 days"
```
**Auto-creates**: Name, dosage, frequency, duration, instructions

#### For Multiple Medications
```
👨‍⚕️ "Injection Ceftriaxone 1 gram IV twice daily,
    Tablet Metronidazole 400 mg three times daily,
    Syrup Antacid 2 teaspoons before meals"
```
**Creates 3 separate medication entries automatically**

### Supported Abbreviations

| You Say | System Understands |
|---------|-------------------|
| "Once daily" or "OD" | Once Daily |
| "Twice daily" or "BD" | Twice Daily (BID) |
| "Three times" or "TDS" | Three Times Daily |
| "Four times" or "QID" | Four Times Daily |
| "Before meals" or "AC" | Before meals |
| "After meals" or "PC" | After meals |
| "Bedtime" or "HS" | At bedtime |

## 🛠️ Troubleshooting

### Common Issues & Solutions

#### 1. AI Scribe Not Working
**Problem**: Microphone not detecting voice  
**Solution**:
- Check browser permissions (allow microphone)
- Use Chrome or Edge browser (best compatibility)
- Ensure no background noise
- Speak clearly and at normal pace

#### 2. Medication Not Auto-Completing
**Problem**: Drug name not appearing  
**Solution**:
- Type at least 3 letters
- Try generic name instead of brand
- Can manually add any medication
- Use common abbreviations (e.g., "Tab PCM" for Paracetamol)

#### 3. Cannot Print Prescription
**Problem**: Print button not working  
**Solution**:
- Click "Download PDF" first
- Open PDF in viewer
- Print from PDF reader
- Check browser popup blocker

#### 4. Patient Not Receiving E-Prescription
**Problem**: Email/SMS not delivered  
**Solution**:
- Verify patient email/phone in profile
- Check spam/junk folder
- Resend from prescription history
- Share PDF link directly via WhatsApp
