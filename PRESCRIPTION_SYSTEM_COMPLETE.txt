PATIENT SIDE:
1. Books video consultation
   POST /api/appointments
   { "consultationType": "video", ... }

2. Joins video call at scheduled time

3. Receives prescription via WhatsApp after call

4. Downloads PDF (no login needed)

5. Can also access from EMR dashboard

DOCTOR SIDE:
1. Conducts video consultation

2. Creates prescription
   POST /api/prescriptions/from-appointment/32
   { "diagnosis": "...", "medications": [...] }

3. Shares via WhatsApp
   GET /api/prescriptions/RX-XXX/share/whatsapp

4. Prescription appears in patient's EMR
