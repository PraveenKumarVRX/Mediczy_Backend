⚡ HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BEFORE (Manual - 8 steps, 5 minutes):
  1. Video call ends
  2. Doctor navigates to prescription page
  3. Select patient
  4. Fill patient details (name, age, gender, phone)
  5. Fill doctor details (name, qualifications, registration)
  6. Add diagnosis & medications
  7. Save prescription
  8. Share via WhatsApp

NOW (Automatic - 3 steps, 2 minutes):
  1. Video call ends → Prescription draft AUTO-CREATED ✨
     ✅ Patient info pre-filled
     ✅ Doctor info pre-filled
     ✅ Consultation type tracked
     ✅ Appointment auto-completed
  
  2. Doctor adds diagnosis & medications (ONLY THIS!)
  
  3. Share via WhatsApp (one click)

SAVES: 5 steps, 3 minutes per consultation! 🚀

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📡 THREE WAYS TO TRIGGER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 1 (RECOMMENDED):
  POST /api/appointments/:id/complete-with-prescription
  
  Use when: Doctor clicks "End Consultation" button
  Result: Appointment completed + Prescription draft created
  
  Response:
  {
    "prescription": {
      "prescriptionId": "RX-XXX",
      "status": "draft",
      "message": "Add diagnosis and medications to finalize"
    }
  }

METHOD 2 (VIDEO INTEGRATION):
  POST /api/video/room/:roomId/leave
  Body: { "appointmentId": 33, "duration": "10 minutes" }
  
  Use when: Doctor leaves video call
  Result: Auto-creates draft if video/audio/chat consultation
  
  Response:
  {
    "prescriptionCreated": true,
    "prescription": { "prescriptionId": "RX-XXX" }
  }

METHOD 3 (LEGACY):
  POST /api/appointments/:id/complete
  Body: { "autoCreatePrescription": true }
  
  Use when: Using existing appointment completion flow
