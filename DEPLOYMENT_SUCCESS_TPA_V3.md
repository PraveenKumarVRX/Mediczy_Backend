## 📱 API Usage Examples

### Get All TPA Providers
```bash
curl -X GET http://localhost:8000/api/tpa/providers \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Submit Claim Intimation
```bash
curl -X POST http://localhost:8000/api/tpa/fhpl/claim-intimation \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "policyNumber": "FHPL123",
    "memberId": "M456",
    "claimType": "cashless",
    "hospitalName": "Apollo Hospital",
    "ailmentDetails": "Cardiac surgery"
  }'
```

### Get E-Card
```bash
curl -X POST http://localhost:8000/api/tpa/nivabupa/ecard \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "policyNumber": "NB123",
    "memberId": "M456"
  }'
```
